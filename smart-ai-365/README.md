# SMART AI 365

واجهة أولية مستقلة لمنصة محادثة ذكاء اصطناعي مجانية، بهوية سوداء وذهبية.

## متطلبات المنتج المعتمدة
- محادثة متعددة اللغات: العربية والإنجليزية والهندية، مع دعم أوسع للغات الأخرى.
- اكتشاف لغة رسالة المستخدم تلقائياً، والرد باللغة نفسها ما لم يطلب لغة أخرى.
- الترجمة والشرح والكتابة والبرمجة والتلخيص والتحليل والمساعدة العامة.
- واجهة عربية أولاً، مع قابلية إضافة واجهات إنجليزية وهندية.
- تصميم متجاوب للهواتف والحواسيب.

## الحالة الحالية
- واجهة عربية متجاوبة للهواتف والحواسيب.
- محادثة تجريبية محلية لتجربة تدفق الواجهة فقط.
- لم يتم ربط نموذج ذكاء اصطناعي حقيقي أو خدمة خلفية بعد.
- لا تضع مفاتيح API أو أسراراً في ملفات الواجهة الأمامية.

## محرك متعدد اللغات مقترح
Qwen3 مرشح أولي لأنه يذكر دعماً لـ119 لغة ولهجة، منها العربية والهندية والإنجليزية. يجب اختبار الجودة الفعلية لكل لغة قبل اعتماد النموذج في الإنتاج، وقد تختلف النتائج حسب اللغة والمهمة وحجم النموذج.

المصدر: https://qwenlm.github.io/blog/qwen3/

## الخطوة التالية
اختيار طريقة استضافة مجانية أو منخفضة التكلفة لتشغيل النموذج أو استخدام حصة مجانية موثوقة، ثم إنشاء خادم وسيط آمن وربطه بالواجهة. لا يمكن ضمان تشغيل غير محدود مجاناً؛ خدمات النماذج المجانية لها حصص أو متطلبات موارد.
