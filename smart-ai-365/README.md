# SMART AI 365

واجهة أولية مستقلة لمنصة محادثة ذكاء اصطناعي مجانية، بهوية سوداء وذهبية.

## الحالة الحالية
- واجهة عربية متجاوبة للهواتف والحواسيب.
- محادثة تجريبية محلية لتجربة تدفق الواجهة فقط.
- لم يتم ربط نموذج ذكاء اصطناعي حقيقي أو خدمة خلفية بعد.
- لا تضع مفاتيح API أو أسراراً في ملفات الواجهة الأمامية.

## المسار
`smart-ai-365/index.html`

## الخطوة التالية
اختيار محرك استدلال مجاني/مفتوح المصدر وخادم وسيط آمن، ثم ربطه بالواجهة مع حدود استخدام واضحة. لا يمكن ضمان تشغيل غير محدود مجاناً؛ خدمات النماذج المجانية لها حصص أو متطلبات موارد.
