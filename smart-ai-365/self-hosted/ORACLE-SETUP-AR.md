# نشر SMART AI 365 من الهاتف — Oracle Cloud Always Free

## القرار المبدئي
الخيار الأقرب لتشغيل Ollama/Qwen3 باستمرار دون دفع شهري هو Oracle Cloud Always Free VM:
- حد الموارد المجاني المعلن لـ Ampere A1 هو ما يعادل 2 OCPU وذاكرة 12 GB ضمن حدود Always Free.
- هذه موارد CPU وليست GPU؛ توقّع استجابة أبطأ، خصوصاً مع عدة مستخدمين.
- توافر السعة يختلف حسب المنطقة وقد يظهر خطأ Out of host capacity.
- إنشاء الحساب يتطلب عادةً رقم هاتف وبطاقة دفع للتحقق. لا تتابع إذا لم تكن مرتاحاً لإدخال البطاقة؛ لا تشارك بياناتها أو رموز التحقق مع أي شخص.

## تنبيه مهم
هذا ليس ضماناً لاستضافة مجانية بلا شروط إلى الأبد. Oracle قد تسترد بعض الموارد الخاملة، وقد لا تتوفر سعة مجانية في كل منطقة. راجع شروط Oracle الحالية قبل الإنشاء.

## إعداد VM المقترح
- Image: Ubuntu 24.04 ARM64 (aarch64).
- Shape: VM.Standard.A1.Flex.
- OCPU: 2.
- Memory: 12 GB.
- Boot volume: ضمن حد Always Free المعروض في لوحة الحساب.
- لا تفتح منفذ Ollama 11434 على الإنترنت.
- لا تفتح API للعامة قبل إعداد HTTPS، ومصادقة أو rate limiting.

## إعداد من هاتف Android
1. افتح https://cloud.oracle.com/ وسجّل الدخول أو أنشئ حساب Oracle Cloud Free Tier.
2. أكمل تحقق الحساب بنفسك. لا ترسل رقم البطاقة أو كلمة المرور أو OTP في المحادثة.
3. افتح القائمة ثم Compute ثم Instances ثم Create instance.
4. اختر Ubuntu ARM64، ثم Ampere A1 Flex، واضبط 2 OCPU و12 GB RAM فقط.
5. تحقق أن التكلفة المقدرة صفر وأن جميع الموارد تظهر ضمن Always Free Eligible قبل الضغط على Create.
6. إذا لم تتوفر سعة، لا تختَر شكلاً مدفوعاً؛ جرّب Availability Domain آخر أو أوقف العملية.
7. بعد إنشاء الخادم، نتابع إعداد Docker وHTTPS. لا تنشر عنوان IP أو SSH private key علناً.

## نشر التطبيق بعد تجهيز الخادم
من مجلد smart-ai-365/self-hosted:
- ثبّت Docker Engine وDocker Compose على Ubuntu ARM64.
- انسخ ملفات هذا المجلد إلى الخادم.
- عيّن ALLOWED_ORIGIN إلى أصل موقع الواجهة فقط.
- شغّل docker compose up -d --build.
- راقب تنزيل النموذج أول مرة عبر docker compose logs -f model-init.
- تحقق من /health بعد نشر API خلف HTTPS reverse proxy.
- اربط عنوان API الآمن في API_URL بملف الواجهة.

## موارد النموذج
الإعداد الأولي يستخدم qwen3:8b. إذا كان الأداء بطيئاً أو الذاكرة غير كافية، نختبر نسخة أصغر مثل qwen3:4b بدلاً من تغيير الخادم إلى مورد مدفوع. اختيار حجم النموذج يوازن السرعة والجودة؛ ولا يضمن 98% دقة.

## الخصوصية والأمان
- لا تضع كلمات مرور أو مفاتيح SSH أو مفاتيح API في GitHub.
- احتفظ بمفتاح SSH الخاص على جهازك فقط.
- لا تشارك رموز OTP أو معلومات البطاقة.
- فعّل جدار الحماية، وافتح 22 من عنوانك الموثوق فقط، و80/443 لخدمة HTTPS عند الحاجة.
